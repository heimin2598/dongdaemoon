전면광고가 표시되지 않던 문제를 바로잡고, 길찾기 기능을 매장 상세에서 바로 시작할 수 있게 했습니다. 화면 곳곳의 표기 오류와 어색한 부분도 함께 정리했습니다.

• 매장 상세에서 '여기까지 길찾기'로 실내 길안내를 바로 시작
• 길안내 단계 안내 문구를 알아보기 쉽게 개선 (엘리베이터·계단 등)
• 층 표기를 '4층'으로 통일 (일부 화면에서 '4F'로 표시되던 문제)
• 층별 보기·길안내 화면의 버튼과 지도 조작 위치 정리
• 비회원 화면에서 사용할 수 없는 메뉴가 보이던 문제 수정
• 사장님 홈에서 매장 정보를 불러오는 중 '매장 없음'으로 보이던 문제 수정
• 부자재 찾기 화면에 뒤로가기 추가
• 앱 정보의 점포 수를 실제 등록 수(3,689개)로 표시
