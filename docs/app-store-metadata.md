## Description / 설명 (iOS 4,000자 / Google Play 4,000자)

```
동대문 종합시장 셰르파는 동대문 종합시장 A·B·C·D·N동 3,689개 점포를 빠르게 찾고
방문 동선을 짤 수 있는 점포 가이드 앱입니다.

【주요 기능】

▶ 점포 검색
- 상호명 / 카테고리 / 호수로 빠른 검색
- 원단·부자재·실·레이스·편의시설·식당가·카페 등 빠른 카테고리 칩
- 검색 결과를 지도 위치와 함께 즉시 확인

▶ 시장 지도 (A/B/C/D/N동 전 층)
- 동·층별 매장 배치를 한눈에
- 화장실·엘리베이터 등 편의시설 표시
- 한눈에 보기 — 동·층별 주요 카테고리 한 페이지 정리
- 시작점 → 목적지 길안내 (시장 안에서 이동 동선)

▶ 부자재 찾기 (프리미엄)
- 단추·지퍼·실·레이스 등 카테고리 선택해 한 번에 요청
- 동대문 종합시장 사장님들이 답글 — "우리 매장에서 찾아봐요"
- 매장 답글에서 바로 매장 상세로 이동

▶ 매장 사장님 모드
- 사장님 회원가입 → 운영자 승인 후 매장 등록
- 매장 정보 (상호·호수·전화·영업시간·소개·취급 카테고리) 직접 관리
- 방문자와 1:1 채팅으로 빠르게 안내
- 부자재 요청에 답글 달기

▶ 관심 매장 & 메모 (프리미엄)
- 매장별 텍스트 메모 / 사진 메모 저장 (매장당 사진 10장)
- 관심 매장 리스트 순서 자유 변경

▶ 안전한 커뮤니티
- 리뷰·답글·요청 모두 신고 + 차단 가능
- 차단한 사용자의 모든 콘텐츠 자동 숨김

【프리미엄 안내】
가입 후 30일 무료 체험. 체험 기간 동안 부자재 찾기·메모·포토메모·관심 매장 모두 제한 없이 사용 가능합니다.

【주요 사용자】
- 동대문 종합시장 방문이 잦은 의류·소품 디자이너
- 부자재·원단을 빠르게 찾고 싶은 소공인
- 자신의 매장을 더 많이 알리고 싶은 시장 사장님

피드백·문의: heimin2598@gmail.com
```
